# Спокойнее

Самостоятельный адаптивный гайд о тревоге. React + Vite, без сервера данных.

Запуск: `npm install`, затем `npm run dev -- --host 127.0.0.1 --port 4173`.

Сборка: `npm run build`. Готовые статические файлы — в `dist/client`. Их содержимое можно разместить в корне обычного статического хостинга. В проекте также сохранён стандартный Worker шаблона для возможной публикации через Sites.

Тексты: `src/content.js` и `src/App.jsx`. Оформление: `src/source.css` и `src/styles.css`. Изображения и шрифты: `public/assets`.

На сайте отсутствуют имя, фотография, биография, контакты, личные истории и коммерческие предложения автора референса. Нет сторонней аналитики и внешней загрузки ресурсов. Имена писателей оставлены как библиографическая информация. Сохранены четыре тематические иллюстрации из референса; уникальность оформления или неузнаваемость источника не гарантируется.

Для описаний тревоги и мягкого дыхания сверены публичные материалы NHS:
- https://www.nhs.uk/every-mind-matters/mental-health-issues/anxiety/
- https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/breathing-exercises-for-stress/

Материал образовательный, не медицинская диагностика. Публичная публикация в этой задаче не выполнялась.
