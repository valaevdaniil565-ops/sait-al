# Алёна Почернина — психолог

Адаптивный образовательный сайт о тревоге на React + Vite. Оформление: шрифт Onest, молочный фон, сливовые акценты, фотография природы и блок знакомства с психологом.

Запуск: npm install, затем npm run dev. Сборка: npm run build; статические файлы находятся в dist/client. Vercel публикует ветку main: https://sait-al-saq2.vercel.app/.

Тексты: src/content.js и src/App.jsx. Оформление: src/styles.css. Ресурсы: public/assets. Имя и профессия предоставлены пользователем; стаж, образование, отзывы и контакты не выдуманы. Материал образовательный и не заменяет консультацию специалиста.
